# 나율이 키우기

나율이를 0살부터 100살까지 키우는 웹 육성 게임이에요. `index.html` 파일 하나로 되어 있어요.

- 밥, 씻기, 잠, 놀이로 나율이를 돌봐요. 대부분 짧은 미니게임으로 해요.
- 1년이 실제 1시간이에요(설정에서 바꿀 수 있어요). 창을 닫아도 시간이 흘러요.
- 강아지, 고양이, 토끼를 반려동물로 키울 수 있어요.
- 동글동글한 마을 풍경이 실제 시각(낮·밤)과 계절(봄·여름·가을·겨울)에 맞춰 바뀌어요.
- 독감, 태풍, 신종 바이러스 같은 일이 생겨요.
- 100살이 되면 인생 앨범을 볼 수 있어요.
- 🏆 순위: 재능·행복·나이·가족·반려동물로 인생 점수를 매겨요. GitHub 페이지에서는 이 기기 기록만 보여요.
- 👫 친구: Claude 링크에서 친구와 같이 열면 친구의 나율이가 마을에 놀러 와요. 인사, 선물, 정해진 말을 주고받을 수 있어요.

## 하는 법

`index.html`을 브라우저로 열면 돼요. GitHub Pages를 켜면 인터넷 주소로도 할 수 있어요.
