# 나율이 키우기

나율이를 0살부터 100살까지 키우는 웹 육성 게임이에요. `index.html` 파일 하나로 되어 있어요.

- 밥, 씻기, 잠, 놀이로 나율이를 돌봐요. 대부분 짧은 미니게임으로 해요.
- 1년이 실제 1시간이에요(설정에서 바꿀 수 있어요). 창을 닫아도 시간이 흘러요.
- 강아지, 고양이, 토끼를 반려동물로 키울 수 있어요.
- 동글동글한 마을 풍경이 실제 시각(낮·밤)과 계절(봄·여름·가을·겨울)에 맞춰 바뀌어요.
- 독감, 태풍, 신종 바이러스 같은 일이 생겨요.
- 100살이 되면 인생 앨범을 볼 수 있어요.
- 🏆 순위: 재능·행복·나이·가족·반려동물로 인생 점수를 매겨요. GitHub 페이지에서는 이 기기 기록만 보여요.
- 👫 친구: Claude 링크에서 친구와 같이 열면 친구의 나율이가 마을에 놀러 와요. 인사, 선물, 정해진 말을 주고받을 수 있어요.

## 하는 법

`index.html`을 브라우저로 열면 돼요. GitHub Pages를 켜면 인터넷 주소로도 할 수 있어요.

# 삼도류 검사 (Three-Sword Style)

`knight.html` 하나로 된 칼 세 자루(오른손·왼손·입)를 쓰는 검사를 키우는 오리지널 2D 도트 액션 플랫포머예요.

- 10개 월드 × 4스테이지 = 40스테이지: 숲, 동굴, 성벽, 사막, 설원, 늪, 용암, 하늘섬, 폐허, 공허
- 월드마다 x-4는 서로 다른 보스: 바위왕, 슬라임 대왕, 흑기사, 모래 지렁이, 서리 마녀, 독두꺼비, 화염 정령, 폭풍 그리폰, 해골 사령술사, 별을 삼킨 자(3페이즈, 가장 어려움)
- 적을 쓰러뜨려 레벨업(체력·공격력 상승), Lv5 회오리베기(땅에서 ↓+공격), Lv8 검기 날리기(3타)
- 3단 콤보(오른손 베기 → 왼손 올려베기 → 삼도 교차베기), 2단 점프, 벽 점프, 대시, 별 던지기(주워 모은 별을 써요), 공중 ↓+공격 내려찍기
- 스테이지 사이 상점에서 검 10종(오른손·왼손·입 칸에 따로 끼워요, 공격력은 세 자루 평균), 칼 강화 +1~+10(명검 → 대명검 → 전설 → 신검 각성), 별 10종(쌍둥이·번개·관통·부메랑·폭발·세 갈래·추적·유성·은하), 갑옷 10종(체력·무적 시간)을 사서 바꿔 껴요. 진행 상황은 이 기기에 저장돼요.
- 키보드: A/D 이동 · W/Space 점프 · J 공격 · K 대시 · L 투척 · Esc 일시정지 · M 소리
- 휴대폰에서는 왼쪽 조이스틱과 오른쪽 버튼으로 해요. 게임패드도 돼요.
- 🏆 순위: Claude 링크에서 열면 모두의 기록(도달 스테이지·시간)을 함께 봐요. GitHub Pages에서는 Supabase를 연결하면 모두의 순위가 보여요(설정 전에는 이 기기 기록만).
